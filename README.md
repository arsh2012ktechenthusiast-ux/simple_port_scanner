# 🔍 Python TCP Port Scanner

A fast and simple multithreaded command-line port scanner written in Python.

## Features

- **Interactive CLI**: Prompts for target host and port range.
- **Domain & IP Support**: Resolves hostnames or takes IP addresses directly.
- **Multithreaded**: Scans ports concurrently for fast results.
- **Zero Dependencies**: Uses Python standard library only (`socket`, `threading`, `sys`).

## Usage

1. Run the script:
   ```bash
   python3 port_scanner.py
